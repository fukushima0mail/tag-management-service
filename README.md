# movieへのタグ付けアプリ

指定したフォルダ内の動画・画像をサムネイル一覧で表示し、タグ付け・絞り込み・並び替えができるデスクトップアプリです。

### 必須ライブラリ
- ffmpeg（本体。`ffmpeg` / `ffprobe` に PATH が通っていること）
  - Windows: `winget install Gyan.FFmpeg`
- ffmpeg-python
- PyQt6
- Pillow

```
pip install PyQt6 ffmpeg-python Pillow
```

### テスト
```
pip install pytest
python -m pytest
```
- 画面を表示せずに実行します。DB・設定・テスト用の画像はすべて一時フォルダに作られ、実際のアルバムや設定には触れません

### 起動
```
python app/main.py
```
DB は起動したディレクトリの `albums/` フォルダに、アルバムごとに作成されます。

アプリアイコンは `app/assets/icon.ico` です。デザインを変える場合は `tools/make_icon.py` を編集して `python tools/make_icon.py` で作り直します。

### 機能
- **アルバム**: 1アルバム = 1DB。登録ファイル・タグ・評価・登録フォルダはアルバムごとに別々に管理されます
  - 上部の「アルバム:」で切り替え、「…」から **新しいアルバム...** / **アルバム名を変更...** / **アルバムを削除...**
  - 「…」→ **タグ・評価をエクスポート...** / **インポート...** で、タグ・評価を JSON に書き出し・読み込みできます（バックアップや別PCへの移行用）
    - インポートはパスで照合し、見つからなければサイズと更新日時が一致するファイルに反映します（タグは追加のみ、評価は書き出し時に評価済みのものだけ上書き）
    - このアルバムに未登録のファイルには反映されないので、先にフォルダを追加・スキャンしてください
    - 削除するとアルバムのDBファイルがごみ箱へ移動します（動画・画像ファイル自体は削除されません。最後の1つは削除不可）
  - アルバムのDBは `albums/` フォルダに作成されます（アルバムが1つもなければ `マイアルバム` を自動作成）
  - 最後に開いたアルバムは次回起動時にも開きます（スキャン中は切り替え不可）
- **フォルダを追加**: フォルダ（サブフォルダ含む）内の動画・画像を読み込み、サムネイルを生成して登録
  - 読み込み時に拡張子が `拡張子:mp4`, `拡張子:jpg` のような形で自動的にタグとして付与されます（絞り込みパネルでは「拡張子」グループにまとまります）
    - 旧形式の拡張子タグ（`mp4` など）は、起動時に自動で新形式へ置き換えられます
  - 追加時に、フォルダ内のすべてのファイルに付けるタグをカンマ区切りで指定できます
    - 「登録済みのファイルにはタグを付けない」にチェックすると、新しく登録するファイルにだけ付与します
  - 追加したフォルダは記憶され、**再スキャン**で新規・変更ファイルを反映、削除されたファイルを一覧から除去します
  - アプリの外で移動・リネームしたファイル（フォルダ名の変更も含む）は、サイズと更新日時が同じなら同じファイルとみなし、タグ・評価を引き継ぎます
  - スキャン中はステータスバーの **中止** で止められます（処理済みのファイルは登録されたまま、削除の反映は行いません）
  - 一度除外したファイル・フォルダも、そのフォルダを追加し直すと再登録されます
- **ファイルを追加**: 動画・画像ファイルを個別に選んで登録（複数選択可、タグの事前指定も可）
- **名前を変更**: 選択したファイルの名前を変更（F2）。実ファイルもリネームされ、タグ・評価は引き継がれます（拡張子は変更不可）
- **ファイルを削除**: 選択したファイルをごみ箱へ移動し、DBからも削除（Shift+Delete）
- **DBから除外**: 選択したファイル（右パネルのボタン / Delete キー）や、選択したフォルダ内のファイル（**フォルダを除外...**）をDBから外します
  - ファイル自体は削除されません。除外したものは再スキャンでは再登録されません
- **タグ編集**: サムネイルを選択し、右パネルでタグを追加・削除（Ctrl / Shift で複数選択して一括編集）
- **絞り込み**: ファイル名検索、種類（動画 / 画像）、タグ（AND / OR）
- **タグのグループ化**: `年代:2020` のように「グループ:値」の形でタグを付けると、絞り込みパネルで「年代」の下にまとめて表示されます（全角の `：` も可）
- **タグ名の一括変更**: 絞り込みパネルのタグを右クリック →「タグ名を変更...」で、全ファイルのタグ名をまとめて変更（既存のタグ名にすると統合）
  - グループ見出しを右クリックすると「グループ名を変更...」「グループを解除」ができます
  - 既存のタグ `2020` を `年代:2020` に変更すれば、グループに移せます
- **評価**: 右パネルで 1〜10 の10段階評価を設定（複数選択で一括設定）
  - 評価済みのファイルは、サムネイル下端に★で表示されます
- **並び替え**: 名前・フォルダ・追加日時・更新日時・サイズ・再生時間・評価（昇順 / 降順）
- **パネルの最小化**: 絞り込み・ファイル情報パネルは見出しの「－」で最小化し、上部の「絞り込み」「ファイル情報」ボタンで再表示（状態は次回起動時も維持）
- **ファイル名の表示切り替え**: 上部の「ファイル名」ボタンで、サムネイル一覧のファイル名を非表示にできます（ツールチップには引き続き表示。状態は次回起動時も維持）
- サムネイルをダブルクリックすると既定のアプリでファイルを開きます
- サムネイルを右クリックすると、開く・**エクスプローラーで表示**・**パスをコピー**（Ctrl+Shift+C、複数選択時は1行に1つ）・**Googleで検索**（拡張子を除いたファイル名で検索）・名前を変更・DBから除外・ファイルを削除のメニューが出ます
